Quiet Snow

Free snow for your Mac or Windows desktop. It settles on your windows, slides off when you drag them, and stays out of your way.

Download for Mac Download for Windows Source on GitHub

The numbers

PriceFree. MIT licence.
MemoryAbout 44 MB on a Mac, 28 MB on Windows.
CPU5 to 8% of one core in CI, on virtual machines. It stops completely when the screen sleeps or locks.
NetworkNone. No account, no tracking. The Windows program does not link the networking libraries at all.
NeedsmacOS 13 or later, or Windows 10 version 2004 or later.

What it does

Snow falls, lies along the tops of your windows and the Dock or taskbar, slides off when you move a window, and flies when you sweep the cursor through a pile. Snowmen build themselves on deep snow and fall apart into snowballs when you move the window; a little plough clears the bottom of the screen now and then. Six snow types: balls, snowflakes, sleet, sparkles, hail, or a mix. Desktop only mode keeps it behind your apps and hides it completely on a display where an app is full screen.

Install

Windows: unzip, double-click QuietSnow.exe. Or with Scoop:

scoop bucket add finntech3 https://github.com/FinnTech3/quiet-snow
scoop install quiet-snow

Mac: unzip, open QuietSnow.app. Or in Terminal:

curl -fsSL https://raw.githubusercontent.com/FinnTech3/quiet-snow/main/install.sh | sh

The honest bit

It is not code signed yet, so Windows SmartScreen or macOS may warn you. Every Windows release carries a SHA256 file and a build attestation, and the source is public. CI builds and tests both apps and renders real frames, but I have not watched it on a real desktop, and the page on GitHub says exactly what is and is not proven.
